# 1.1.10 停止记录：压缩会话声明回归

冻结版本 `f9122bc`，分析器 `authz-java-1.1.10`。本轮计划十八项，实际进入五项后主动停止，SDK 报告合计 82,232 Token；首次失败不删除、不替换。完整记录保存在本地 `artifacts/hardening-v1110-manifest*`。

输出配额已恢复到配置值，但会话压缩实现只保留了用户视图，丢掉了 Pi 1.3.0 放在系统消息里的原始规则和工具声明。实际请求的 tool_count=0，导致 required 工具调用不成立或只能输出普通文本；这些结果不被当作授权分析成功。

这是工具实现的回归，不是被测项目的问题，也不能归咎于模型无法分析授权。发现后停止本轮，不继续花费验证相同缺陷。原协议 fixture 的模拟供应商没有强制检查实际工具列表，导致测试未发现；1.1.11 为此增加系统规则和工具声明的独立回归。

1.1.11 使用 SDK 官方 transcript 辅助函数折叠系统消息与工具增删声明，保留原系统规则后追加有界源码视图；工具声明缺失时在发起请求前拒绝。不放宽证据或字段校验。
