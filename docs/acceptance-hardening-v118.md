## 改进、剩余问题与进入条件

已验证的改进：N1/N5 都在原预算内形成多操作提交；N1 目标成员检查有比较、拒绝与 SQL 依据；角色列表的 Mapper 忽略声明不再遗漏；预算、一次修正及全轮停止机制实际生效。没有为通过验收放宽证据、字段或操作引用。

尚未满足：

1. bindings.source 等自然语言字段来源仍可能与固定输入不一致，现有 fields 校验不足以阻止此类错误。
2. 核心操作与观察详情可能相互矛盾；范围文字也可能把已读方法误写为未读。程序事实台账不等于模型描述已自动得到验证。
3. 初次提交的锚点与字段引用不稳定，一次修正会再次重复长上下文；预算预留能阻止超额调用，但不能保证修正成功。
4. 注解检查的配置条件与执行效果表达仍偏保守；不能将未知代理当成确定无效，也不能在未证明时直接变成有效保护。
5. 十个真实接口和八个语义对照未完成同版本全部验收，进入批次四的门槛不满足。

后续应围绕通用的字段来源映射、已读锚点反馈、条件式检查及跨说明一致性整改；不是增加 case 答案或取消严格校验。若再次修改代码或提示词，应另建版本与冻结清单。本轮已停止，不自动追加收费重验。
