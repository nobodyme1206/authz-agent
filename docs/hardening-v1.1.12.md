# Stage 2 1.1.12：恢复兼容工具选择

本版保留 1.1.9—1.1.11 的字段来源、赋值说明、证据编号、有界源码视图、系统/工具声明保留和 SDK 级单次纠错。

撤销供应商拒绝的 required 工具选择，不修改用户模型、上下文大小、Token/轮次/工具/时间上限或供应商 thinking 参数。最终阶段只声明提交工具，由系统规则要求提交，程序严格校验；普通文本仍不能成为有效成果。

实际供应商请求记录最大输出、工具数量、工具选择、thinking 和 reasoning_effort 参数是否出现。Pi thinkingLevel=off 与供应商默认推理模式分别表达，不宣称未实际发送的禁用配置已经生效。

全局模型接口错误会保存停止状态，禁止误将同一冻结清单再次执行为续跑。前序三轮保守占用 421,278 Token，当前新轮与其合计受 1,080,000 Token 规划额度约束。失败、取消、未执行与 SDK 可见费用全部单独保留，不拼接通过成绩。
