# Stage 2 1.1.11：保留系统规则与提交工具

本版延续冻结字段、已读证据编号、赋值说明校验、SDK 上下文规划和有界单次纠错。公共格式仍为 v0.4，不实现 Stage 3/4。

修正 1.1.10 的会话压缩回归：Pi 1.3.0 在系统消息内维护工具声明及其增删。压缩时通过官方 getCurrentSystemMessage/getCurrentTools 折叠当前系统状态，保留所有系统规则与当前工具，再追加有界原始源码视图。工具缺失时在供应商请求前拒绝，不能向无工具请求声明 required。

新增测试直接检查最终供应商请求包含系统规则和 submit_authorization；覆盖工具增删声明、SDK 截断后纠错和上下文压缩后的实际最大输出。早期 fixture 只校验返回结构而未验证真实工具列表，相关断言已补齐。

真实复验另建固定版本；1.1.9 与 1.1.10 的首次失败、主动停止和费用单独保留。本次之前保守占用 413,058 Token，后续任务继续受总规划 1,080,000 Token 约束，不因新版本重置额度。取消任务预留完整预算，规划估算不是精确账单或供应商硬上限。
